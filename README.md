# ZXVI OneAI Toolkit

A single-file, **fully offline** toolkit with **220 tools** – no API keys, no servers, no accounts, no tracking. Everything runs in the browser.

- **Mobile-app style UI** that becomes a true full-window desktop workspace on wide screens
- **Smart search** – type what you want to do ("shrink a photo", "solve a sudoku from a picture") and it finds the tool
- **ZXVI mascot assistant** – a tappable pink-haired anime lab-coat mascot that reacts to what you ask (expressions, eye tracking, speech bubble). It speaks English out loud with a voice picker, understands "which tool can make a PDF?" style questions, supports voice input on browsers that allow it, offers menus in 20 languages, and has a bigger offline knowledge pack: countries and capitals, Indian states, the periodic table, full forms, phrases in 12 languages, letter templates, code answers and more. It is rule and retrieval based (not an LLM) and can optionally use your browser's built-in AI as a fallback
- **40 colour themes** (plus light / dark / system), saved on the device
- **Word Search solver** – type or *scan a photo of a puzzle* (offline OCR), then reveal answers one by one or print the solved sheet
- **Sudoku** – play, generate, type your own, or *scan a photo* and solve it step by step
- **Image to Story** – drop in a picture and get a story built from its colours, light and mood (template based, works offline – it does not "recognise" objects, so add a hint for better stories)
- **Video Link Helper** – paste a YouTube link to save its thumbnail in every size, download a direct media link, or pull the audio (WAV) or a still frame out of a video file you already have. It does not download videos or audio from YouTube, Instagram, TikTok and similar sites
- **PDF tools** – translate a PDF into another language (browser's on-device translator, or paste a translation from any website), Image to PDF, PDF to Text and PDF to Images
- **Team tool sections** – Soumya, Keerthana, Ananth and Sanjay unique tools (10 each): task planners, quiz/receipt helpers, submission & file-requirement checkers, household stock, group expense splitting, cost-per-wear, refill prediction and more. All rule-based and offline.
- **Profile** – name, username, bio, emoji / photo avatar, accent colour, export / import backup (stored in the browser)
